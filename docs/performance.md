# Аудит производительности

Порог для главной страницы: **Lighthouse Performance не ниже 90**, LCP < 2,5 с, CLS < 0,1 и INP < 200 мс.

## Результаты

Замеры выполнены в Docker на одной машине и в одном мобильном профиле Lighthouse 12.8.2.

| Метрика | До оптимизации | После оптимизации |
|---|---:|---:|
| Lighthouse Performance | 73 | 98 |
| LCP | 1 999 мс | 1 977 мс |
| CLS | 0,924 | 0,004 |
| Передано данных | 3 796 КБ | 497 КБ |
| INP (Playwright Event Timing) | 56 мс | 72 мс |

INP в лабораторном тесте зависит от скорости машины, поэтому важен порог, а не разница в несколько миллисекунд. Оба результата находятся в «хорошей» зоне Core Web Vitals.

## Что проверяется автоматически

`e2e/tests/performance.spec.js` проверяет LCP, CLS и INP, подтверждает фактический выбор AVIF браузером и падает при выходе за установленные пороги.

Запуск:

```bash
docker compose -f docker-compose.e2e.yml run --build --rm e2e npx playwright test tests/performance.spec.js
```
